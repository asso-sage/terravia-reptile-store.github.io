# 🌿 TERRAVIA — Reptile & Terrarium Store

> Premium terrariums, reptile habitats, and accessories designed for natural, functional, and beautiful environments.

## 🦎 About
TERRAVIA is a premium ecommerce concept focused on terrariums, reptile habitats, lighting, heating, natural decor, substrates, humidity, monitoring, feeding accessories, and habitat care.

The experience combines a botanical visual identity with a modern ecommerce interface, responsive layouts, product interactions, and a local asset structure suitable for GitHub Pages.

## ✨ Features
- Premium dark botanical visual identity
- Responsive desktop, tablet, and mobile layout
- Product catalog with category filtering
- Search interaction
- Product detail modal
- Shopping bag with localStorage persistence
- Favorites interaction
- Newsletter interaction
- Responsive navigation
- Local image assets
- Optimized JPG logo and product photography assets
- Support/contact section
- GitHub Pages-friendly static architecture
